欢迎使用MemoDesign！   
MemoDesign由Python制作。   
您可以使用MemoDesign制作2D平面瓦片地图。   
  
同时，我也使用MemoDesign制作我新独立游戏的地图。   
接下来，本文会详细介绍如何使用MemoDesign制作你的地图。   

#画

首先，你应该新建一张地图，地图总是mdmap格式的。   
然后，你需要新建一份瓦片文件，瓦片文件存储你所有的瓦片。   
打开编辑器即可创建一份mdtile瓦片文件，你需要为文件填充唯一的id和其他数据，包括图片的路径。   
你需要注意的是，图片总是使用本地路径，所以如果需要把瓦片传递给你的朋友，就需要其他的方式。   
在编辑器中，你可以使用笔刷，橡皮，填充等工具绘制你的地图。     
瓦片在地图右侧，被分组显示。右键可以拖拽你的地图。      
如果你上传了瓦片图像，那么瓦片会正确显示你的图像，否则，就会显示瓦片的名称。     

#属性

当你绘制完成你的瓦片，你一定想要一个起点和终点。   
点击属性绘制工具，就可以绘制属性了。    
除了 起点 终点和钥匙点位以外，还有跳转格。   
跳转格可以使你从一张地图跳转到另一张。  

#完成了 
 
你完成了瓦片绘制。     
你会获得一份mdmap和mdtile文件。    
你或许希望你能够获得一份JSON格式的瓦片文件，那么就可以选择导出到json。
